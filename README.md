# A/B Test Simulation & Statistical Power Tool

A web-based interactive application built with **Streamlit** to simulate A/B test data, perform hypothesis testing (Welch's t-test), and conduct statistical power analysis under various conditions.

## ✨ Key Features

1. **Single A/B Test Simulation**
   - Generate custom A/B test datasets or use pre-defined industry scenarios (e.g., E-commerce conversion, SaaS signup, Media lead generation).
   - Perform Welch's t-test to determine statistical significance.
   - View clear summaries, conversion rates (CVR), p-values, and automated conclusions.

2. **Statistical Power & Type I Error Analysis**
   - Run simulations across multiple sample sizes and effect sizes (true CVR differences).
   - Visualize the relationship between sample size and statistical power using interactive charts.
   - Export simulation results as a CSV file for further analysis.

## 🛠️ Built With

- **Python**
- **Streamlit** (Interactive UI)
- **Pandas & NumPy** (Data processing & simulation)
- **SciPy** (Statistical testing)
- **Matplotlib & Seaborn** (Data visualization)
